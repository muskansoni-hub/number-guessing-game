# Number Guessing Game
[click here to play this game https://number-guessing-game-dohzbtme2wktkx6ds4zbrs.streamlit.app/]

A simple Python game in which the computer selects a random number
and the player tries to guess it.

## Features

- Random number generation
- Checks whether the guess is too high or too low
- Congratulates the player on a correct guess

## Requirements

- Python 3

## How to Run

1. Install Python 3.
2. Open the terminal in this project folder.
3. Run:

   python guessing_game.py
